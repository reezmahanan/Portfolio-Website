# 🌟 Reezma Hanan - Personal Developer Portfolio

Welcome to the official repository of my developer portfolio! This is a modern, premium, responsive single-page web portfolio showcasing my academic credentials, software engineering projects, open-source contributions, and certificates.

> [!NOTE]
> This website is built using raw **HTML5, CSS3 (Vanilla), and ES6+ JavaScript** with zero heavy frameworks, ensuring fast loading speeds, smooth animations, and optimized mobile views.

---


---

## 🚀 Key Features

*   **Premium Space-Dark Glassmorphism**: Stunning UI aesthetics with glowing borders, translucent background backdrops, and hover micro-animations.
*   **Animated Profile Circle**: A custom rotating badge displaying `REEZMA HANAN • DEVELOPER •` spinning in sync with dual dashed/dotted boundary rings.
*   **Dynamic Counter Increments**: Viewport triggers that count up stats (`15+ Techs`, `8+ Projects`, `20+ Certs`) on page entry.
*   **Collapsible Certifications Drawer**: Keeps the UI neat by placing 23 foundation certificates and interactive search sub-filters behind a "View Additional Foundations & Credentials" summary toggle.
*   **Open Source Grid**: An interactive card showcase of my contributions to **SWOC**, **OSCG**, **SSOC**, and **GSSOC** with direct repository links.
*   **Verified Academic & Platform Badges**: Real credential attachments from UOM CODL, Cisco Networking Academy, Simplilearn, and Linux Foundation.
*   **Full Form Validation & Alerts**: Client-side input sanity checks (regex emails, min-length messages) linked to a customized success notification popup.

## 🏃 Local Setup & Run

No compilation or build servers are required! Simply clone the directory and open `index.html` in any browser.

```bash
# Clone the repository
git clone https://github.com/reezmahanan/Portfolio-Website.git

# Navigate into the folder
cd Portfolio-Website

# Run a quick local server (Optional - python)
python -m http.server 8000
```
Then visit `http://localhost:8000` in your web browser.

## 📬 Contact Form Handler

The email message box is powered by **FormSubmit.co** (a free, zero-config email forwarder):
1. Submissions are processed on submit.
2. The form triggers validation checks inside `portfolio-script.js`.
3. Valid messages are forwarded directly to `reezmahanan@gmail.com` with auto-responses configured.
