## ⭐ Featured Project: BookHaven E-Commerce Platform

<div align="center">

### 📚 NETH BookHive - Complete E-Commerce Bookstore

coming 🔜 

</div>

**BookHive** is my flagship project - a fully functional e-commerce platform specializing in Psychology & Finance books for the Sri Lankan market.

### 🌟 Key Features:
- 🛒 **Complete Shopping Cart** - Add, remove, quantity management
- ❤️ **Wishlist System** - Save favorite books for later
- 🔍 **Advanced Search & Filters** - Category, author, price, rating filters
- 📱 **Mobile Responsive** - Perfect experience on all devices
- 🇱🇰 **Sri Lankan Market Focus** - LKR pricing (₨999-₨2,500), local branches
- 🗺️ **Location Tracking** - Geolocation integration with refresh functionality
- 📧 **Contact System** - Professional form with email validation

### 🛠️ Technologies Used:
- **Frontend:** HTML5, CSS3, JavaScript ES6+
- **Storage:** localStorage for data persistence
- **APIs:** Open Library Covers API, Geolocation API
- **Design:** Responsive design with CSS Grid & Flexbox
- **Features:** 30+ curated books, real-time cart updates, smooth animations
